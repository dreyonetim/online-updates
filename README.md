# Yeni Dünya

Resmi oyun kurulumları ve otomatik güncelleme dosyaları.

- [Windows güncelleyici kurulumu](https://github.com/dreyonetim/online-updates/releases/latest/download/YeniDunya-Windows-Guncelleyici-Setup.exe)
- [Mac başlatıcı](https://github.com/dreyonetim/online-updates/releases/latest/download/YeniDunya-Mac-Launcher.zip)

İlk kurulumda oyun verileri indirilir. Sonrasında oyunu başlatıcıyla açtığınızda yalnızca değişen parçalar indirilir ve oyun açılır.

Mac (macOS 13 veya yeni): ZIP'i açıp Yeni Dunya uygulamasını Uygulamalar klasörüne taşıyın. Bu test sürümü henüz Apple notarizasyonuna sahip değildir. Güvendiğiniz resmi dosya için Sistem Ayarları → Gizlilik ve Güvenlik → Yine de Aç adımını kullanabilirsiniz. Sistem güvenliğini kapatmayın.

Kaynak kod burada bulunmaz. Kayıtlar güncelleme sırasında korunur. Herkese açık indirme bağlantıları GitHub hesabı gerektirmez.

İlk indirme yaklaşık 1,7 GB; kurulum ve güncellemeler için yaklaşık 10 GB boş alan önerilir.
